# Konpeito

A self-hosted feed reader for Cloudflare Workers and D1.

Demo: [sample.konpeito.shikakun.com](https://sample.konpeito.shikakun.com)

## Install

```sh
npx @shikakun/konpeito@latest setup
```

## Update

```sh
npx @shikakun/konpeito@latest update
```
